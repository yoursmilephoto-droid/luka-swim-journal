# Дневник плавания Луки

Готовый статический сайт для GitHub Pages. Страница, графики и история заплывов работают без сервера и без входа в GitHub. Опубликованный файл `starts.json` служит источником данных для всех устройств.

## Публикация

Загрузите содержимое этого архива в корень репозитория. В **Settings → Pages** выберите **Deploy from a branch**, основную ветку и папку **/ (root)**. GitHub покажет ссылку после публикации.

## Добавление результата

1. Откройте журнал → **Для родителя → Редактировать журнал**.
2. Нажмите **Добавить результат** или **Изменить** рядом с существующей записью. Укажите дату, дистанцию, стиль, длину бассейна, статус, время и страницу итогового протокола.
3. Сохраните черновик, скачайте `starts.json` и загрузите его в корень того же репозитория поверх старого файла. После обновления Pages результат появится у всех.

Время в JSON хранится в сотых долях секунды. Для подтверждённого результата ставьте `verified`. Для дисквалификации ставьте `dq` и оставляйте время пустым. При отсутствии первичного документа используйте `pending`. В график попадают только подтверждённые времена. Сравнение требует одинаковой дистанции, стиля и длины бассейна.

В репозиторий достаточно включать журнал одного спортсмена. Полные PDF с данными других детей храните в своём архиве.
